# Error codes from the added manuals

Each JSON matches one added PDF and uses exactly the requested `Error Codes` array with `errorCode`, `errorMeaning` and `possibleSolution` string fields. Codes retain their prefixes, ranges and wildcard notation. Empty arrays mean the PDF contains no named code list; they do not mean the equipment has no errors. Empty solution strings mean no per-code remedy was provided.

PDF page numbers are 1-based positions in the corresponding repository PDF, rather than printed page labels. Samsung part 2 pages 19–20 correspond to original pages 45–46. The duplicate Vaillant upload was already deduplicated when the PDFs were added.

Grant source footnotes: discharge-sensor open circuit is displayed 10 minutes after operation starts; a short circuit is displayed immediately. When checking fan motors or the pump, the manual instructs the technician to turn the power supply off completely and check at the terminal or connector. The source contains some legacy model labels and apparent typographical errors; no unsupported correction to technical conditions has been made.

These files are source extractions, not a complete service-code database for every model. In particular, the Daikin file contains only the three codes mentioned by the installation manual; Samsung provides meanings but no code-specific remedies. Existing app error-code JSON files remain unchanged.

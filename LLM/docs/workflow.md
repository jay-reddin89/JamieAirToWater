# Working workflow

## Begin work

Read project context and current state. Check the task board and inspect the actual checkout before relying on recorded status. Define the requested outcome and identify constraints.

## Plan and create

For substantial work, copy a plan or task template. Define scope, acceptance criteria, and useful validation. Capture drafts and ideas in notes. Store reusable creation prompts in `prompts/`.

## Execute and verify

Keep task status current. Link findings, implementation files, and validation evidence. Distinguish completed work, proposed work, blockers, and checks that were not run.

## Document and hand off

Record meaningful choices in the decision log. Update current state and write a session summary containing what changed and the next useful action. Archive outdated documents with a replacement link.

## Keep records useful

Avoid duplicating current status across files. Use relative links. Never store secret values. This folder provides documentation templates; it does not automatically run tasks, perform deployments, or grant authority for future actions.
